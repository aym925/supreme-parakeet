# DARK STREAM WEB

واجهة ويب عربية لاستبدال أوامر بوت Telegram بلوحة تحكم مباشرة. تعتمد على FastAPI وFFmpeg/FFprobe، وتدعم SOLO، وحقوق الفيديو، وGROUP، وإيقاف بث واحد أو كل البثوث، وفحص المصدر، وإنشاء روابط HLS.

## التشغيل الموصى به: Docker

1. ثبّت Docker وDocker Compose على سيرفر دائم (VPS).
2. انسخ `.env.example` إلى `.env`.
3. غيّر `ADMIN_PASSWORD` و`SESSION_SECRET` إلى قيم طويلة وعشوائية قبل فتح الموقع للإنترنت.
4. شغّل:

   ```bash
   docker compose up -d --build
   ```

5. افتح `http://SERVER-IP:8000` وسجّل الدخول بالبيانات التي وضعتها في `.env`.

للتحديث أو مشاهدة السجلات:

```bash
docker compose logs -f
docker compose up -d --build
```

## التشغيل بدون Docker

تحتاج Python 3.11+ وFFmpeg/FFprobe مثبتين على النظام.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# عدّل .env ثم شغّل:
./start.sh
```

## ما الذي يفعله الموقع؟

- **SOLO:** يرسل مصدر HTTP/HTTPS إلى Facebook Live باستخدام مفتاح البث الذي تدخله.
- **إضافة الحقوق:** يعيد ترميز الفيديو ليضع نص الحقوق أسفل الصورة؛ هذا يستهلك CPU أكثر من Copy.
- **GROUP:** يشغّل عدة مصادر مع مفاتيح بث منفصلة وبنمط موحّد.
- **فحص الرابط:** يفحص المصدر باستخدام FFprobe.
- **HLS:** ينشئ قائمة `.m3u8` ومقاطعها ويعرض الرابط عند توفر الملف.
- **إعادة الاتصال:** يعيد محاولة تشغيل FFmpeg بعد انقطاع العملية ما دام البث لم يُوقف يدويًا.
- **سجلات FFmpeg:** تحفظ في `data/logs/` ويمكن الاطلاع على آخر السجلات من لوحة التحكم.

## ملاحظات مهمة

- هذا ليس تطبيقًا مناسبًا لاستضافة الوظائف القصيرة مثل Vercel Functions. يجب تشغيله على VPS أو خدمة حاويات دائمة؛ لأن عمليات FFmpeg وملفات HLS تحتاج وقت تشغيل وقرصًا مستمرين.
- استخدم `PUBLIC_BASE_URL` كرابط HTTPS عام ثابت (مثل `https://stream.example.com`) إذا أردت روابط HLS قابلة للوصول خارج السيرفر. يجب أن يوجّه الدومين إلى هذا التطبيق وأن يسمح منفذ الويب/الوكيل العكسي بوصول ملفات `/streams/`. روابط HLS نفسها عامة لمن يملك الرابط؛ لا تستخدمها لمحتوى خاص.
- إن كانت الخدمة خلف Nginx أو Cloudflare، اضبط HTTPS و`COOKIE_SECURE=true`، وتأكد من إعداد البروكسي بحيث يمرر `X-Forwarded-Proto` بشكل صحيح.
- البثوث وحالة العمليات محفوظة في الذاكرة؛ إذا أُعيد تشغيل التطبيق أو السيرفر فستنتهي عمليات FFmpeg القديمة. مجلد `data/` يحفظ السجلات وملفات HLS لكنه لا يعيد تشغيل البث تلقائيًا بعد إعادة تشغيل التطبيق.
- لا تشارك كلمة مرور لوحة التحكم أو مفاتيح Facebook Live. استخدم مصادر ومحتوى لديك صلاحية بثه.
- أوقف البثوث غير المستخدمة؛ إعادة الترميز قد تستهلك قدرًا كبيرًا من CPU والإنترنت.

## المسارات

- `/` صفحة الدخول أو لوحة التحكم
- `/healthz` فحص حياة بسيط
- `/streams/<id>/index.m3u8` قائمة HLS عند تشغيل HLS

## متغيرات البيئة الرئيسية

| المتغير | الوصف |
|---|---|
| `ADMIN_USER` / `ADMIN_PASSWORD` | حساب لوحة التحكم |
| `SESSION_SECRET` | سر توقيع جلسة الدخول |
| `RIGHTS_TEXT` | نص الحقوق الافتراضي |
| `PUBLIC_BASE_URL` | أصل روابط HLS العام، اختياري لكن موصى به |
| `MAX_STREAMS` | الحد الأقصى للبثوث النشطة |
| `MAX_HLS_JOBS` | الحد الأقصى لوظائف HLS |
| `COOKIE_SECURE` | اجعله `true` عند استخدام HTTPS |
